# GRC 102 — Week 2 Report
## Developing Security Policies and Procedures

**Organization:** NexusTech Solutions  
**Course:** GRC 102 – Information Security Governance  
**Module:** 2 / Week 2  
**Topic:** Developing Security Policies and Procedures

## Overview

This report presents a security policy framework developed for NexusTech Solutions, a mid-sized enterprise resource planning (ERP) company that has grown from 50 to 250 employees and now serves financial and healthcare clients.

The purpose of this exercise is to demonstrate how governance, risk, and compliance principles can be used to create practical security policies and procedures that support business objectives, protect information assets, and meet legal and regulatory expectations.

## Objectives

This report demonstrates the ability to:

- Distinguish between policies, standards, guidelines, and procedures.
- Organize security documentation using a clear governance hierarchy.
- Develop an Acceptable Use Policy (AUP) for employees and other authorized users.
- Create a practical user access request procedure for the Helpdesk.
- Plan security policy communication, training, and implementation.
- Review and update security documentation when business, technology, or risk conditions change.

## Key Themes

The report focuses on the following security and governance themes:

- **Accountability:** Clearly assigning responsibilities to users, managers, Helpdesk staff, and security personnel.
- **Least privilege:** Granting users only the access required to perform their job duties.
- **Policy awareness:** Ensuring that personnel understand their security responsibilities.
- **Consistent enforcement:** Applying security requirements fairly and consistently across the organization.
- **Continuous improvement:** Reviewing policies regularly and updating them when risks, technology, or business requirements change.

## Expected Outcome

A well-structured policy framework gives NexusTech Solutions a foundation for managing security risks and demonstrating due diligence to customers, auditors, and regulators. The policies and procedures in this report are intended to be clear, actionable, and suitable for ongoing review and improvement.
