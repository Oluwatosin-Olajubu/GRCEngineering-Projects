## Learning outcomes demonstrated

- Distinguishing policies, standards, guidelines, and procedures.
- Organizing security documentation into a governance hierarchy.
- Developing an Acceptable Use Policy.
- Defining a practical user access request process.
- Planning security policy communication and training.
- Reviewing policy requirements when technology, business, or risk conditions change.

## Scenario context

The exercise is based on NexusTech Solutions, a mid-sized ERP company that has expanded from 50 to 250 employees and serves financial and healthcare clients. The policy framework is intended to support accountability, least privilege, policy awareness, consistent enforcement, and continuous improvement.
